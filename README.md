# Магазин техніки — Лабораторна робота №2 (Варіант 10)

Консольний Java-застосунок (Java 21 LTS, Apache Maven) для зчитування, валідації та статистичної обробки даних магазину техніки у кодуванні `UTF-8`.

У межах **Лабораторної роботи №2** (гілка `lab2-classes`, Pull Request у `main`, тег `v2.0.0`, Issue `#4`) предметну логіку перебудовано на об'єктно-орієнтовану модель з інкапсуляцією, перевіркою інваріантів, незмінними `record`-типами, розділенням відповідальностей та автоматичним підтягуванням версії з `pom.xml`.

## Архітектура проєкту

- `ua.lpnu.kzp.Main` — точка входу, що делегує розбір аргументів та запуск контролера і повертає код завершення.
- `ua.lpnu.kzp.CliParser` та `ua.lpnu.kzp.CliOptions` — розбір і перевірка параметрів командного рядка (`--help`, `--version`, `--input`, `--output`).
- `ua.lpnu.kzp.StoreController` — координація читання CSV-файлу у `UTF-8`, формування списку `Product`, обчислення `StoreSummary`, вивід результатів та запис звіту.
- `ua.lpnu.kzp.Product` — незмінний клас-сутність товару (`private final` поля, валідація інваріантів у конструкторі, фабричний метод `fromCsv`, форматований `toString` з `Locale.ROOT`).
- `ua.lpnu.kzp.WarrantyStock` — незмінний `record(int warrantyMonths, int stock)` для збереження гарантійного строку та залишку на складі.
- `ua.lpnu.kzp.StoreSummary` — незмінний `record` підсумкових статистичних показників.
- `ua.lpnu.kzp.BuildInfo` — зчитування версії застосунку з `app.properties`, відфільтрованого Maven під час збірки з `pom.xml`.

## Формат вхідних даних (`data/input.csv`)

CSV-файл без заголовків у кодуванні `UTF-8` з роздільником `;`:

    name;category;price;warrantyMonths;stock

Приклад вмісту `data/input.csv`:

    Ноутбук ASUS;Комп'ютери;35000.50;24;15
    Миша бездротова;Периферія;850.00;12;40
    Смартфон;Мобільні пристрої;18999.99;12;25
    Клавіатура;Периферія;-500.00;12;5
    Монітор AOC;Екрани;помилка;36;10

## Збірка, тестування та запуск

Локальна збірка, запуск тестів JUnit 5, статичний аналіз SpotBugs та пакування виконуваного JAR:

    ./mvnw clean verify package

У Windows PowerShell / CMD:

    .\mvnw.cmd clean verify package

Приклади запуску зібраного JAR-файлу:

    java -jar target/lab01-2.0.0-all.jar --version
    java -jar target/lab01-2.0.0-all.jar --help
    java -jar target/lab01-2.0.0-all.jar --input data/input.csv --output out/report.txt

## Підсумкові показники та обробка помилок

Програма обчислює:
- кількість коректних записів (`validCount`);
- середню ціну товару (`averagePrice`, форматування `%.2f` із `Locale.ROOT`);
- найдовшу гарантію у місяцях (`maxWarrantyMonths`);
- загальну кількість товарів на складі (`totalStock`).

Порожні та пробільні рядки пропускаються. Некоректні рядки (неправильна кількість колонок, нечислові або від'ємні значення, порожні назва чи категорія) не зупиняють виконання програми: кожен такий рядок відхиляється та фіксується у консольному виводі й у файлі звіту `out/report.txt` із зазначенням номера рядка та причини помилки.

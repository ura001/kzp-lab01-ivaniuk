# Лабораторна робота №1: Магазин техніки

[![Java CI](https://github.com/ura001/kzp-lab01-ivaniuk/actions/workflows/ci.yml/badge.svg)](https://github.com/ura001/kzp-lab01-ivaniuk/actions/workflows/ci.yml)

## Призначення програми
Консольна програма для обробки даних магазину техніки. Програма читає записи з CSV-файлу, перевіряє їх на коректність, обчислює статистичні показники та формує звіт у консоль і текстовий файл.

## Формат вхідних даних (`data/input.csv`)
Один запис розміщується у рядку, поля розділяються крапкою з комою (`;`). Файл кодується у **UTF-8**.

Поля запису для варіанта 10 («Магазин техніки»):
`name:String; category:String; price:double; warrantyMonths:int; stock:int`

Приклад вхідного файлу:
```text
Ноутбук ASUS;Комп'ютери;35000.50;24;15
Миша бездротова;Периферія;850.00;12;40
Смартфон;Мобільні пристрої;18999.99;12;25
Клавіатура;Периферія;500.00;12;5
Монітор AOC;Екрани;помилка;36;10

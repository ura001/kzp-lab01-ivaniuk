# Магазин техніки — Лабораторна робота №2 (Варіант 10)

Консольний Java-застосунок (Java 21 LTS, Apache Maven) для зчитування, валідації та статистичної обробки даних магазину техніки у кодуванні UTF-8.

У межах **Лабораторної роботи №2** предметну логіку перебудовано на об'єктно-орієнтовану модель з інкапсуляцією, перевіркою інваріантів, незмінними `record`-типами, розділенням відповідальностей (`Main` / `CliParser` / `StoreController`) та автоматичним підтягуванням версії з `pom.xml`.

## Архітектура проєкту

- `ua.lpnu.kzp.Main` — легка точка входу (делегує парсинг аргументів та запуск контролера, повертає код завершення).
- `ua.lpnu.kzp.CliParser` та `ua.lpnu.kzp.CliOptions` — розбір і перевірка параметрів командного рядка (`--help`, `--version`, `--input`, `--output`).
- `ua.lpnu.kzp.StoreController` — координація читання CSV-файлу, формування списку `Product`, обчислення `StoreSummary` та запису звіту.
- `ua.lpnu.kzp.Product` — незмінний клас-сутність товару (`private final` поля, валідація інваріантів у конструкторі, фабрика `fromCsv`, форматований `toString` з `Locale.ROOT`).
- `ua.lpnu.kzp.WarrantyStock` — незмінний `record` для збереження гарантійного строку (`warrantyMonths`) та запасу на складі (`stock`).
- `ua.lpnu.kzp.StoreSummary` — незмінний `record` підсумкових статистичних показників.
- `ua.lpnu.kzp.BuildInfo` — зчитування версії проєкту з `app.properties`, сформованого Maven під час збірки з `pom.xml`.

CSV-файл без заголовків у кодуванні `UTF-8` з роздільником `;`:

name;category;price;warrantyMonths;stock
